VR-Test Cafeteria – equirektangulares Originalpanorama

GitHub:
1. index.html und cafeteria.jpg direkt in das Hauptverzeichnis des Repositorys laden.
2. GitHub Pages auf main / (root) aktivieren.
3. Pages-Webadresse im VIVE Browser öffnen.
4. 'VR starten' anklicken.

Erwartung:
- Panorama füllt im immersiven Modus das Sichtfeld.
- Umschauen erfolgt durch Kopfbewegungen.
- Keine zusätzlichen Cube-Schnittkanten, weil das 2:1-Panorama direkt auf eine Kugel projiziert wird.
